E-Commerce Website UI(Shopping Club)

Description:
Shopping Club is a online shopping website where users can add to cart & buy products. It's built using HTML, CSS, JS.

Features:
Shows headphones, watch,shoes,handbag ets
Each product has a price and add to cart button.
This website also has AI shopping Assistant.

Technologies Used:
index.html
style.css
script.js

How to Run:
Download Repository
Open index.html in browser(open live server)
