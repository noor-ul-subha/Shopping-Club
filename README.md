# Shopping Club_E-Commerce Website UI

## 1. About the Project

Shopping Club is a simple e-commerce website that provides users with an online shopping experience. Users can explore different products, view their prices, search for products, and add items to their shopping cart.

## 2. Objectives

* Create a simple and user-friendly shopping website.
* Display products with images, names, and prices.
* Provide product search functionality.
* Implement a basic shopping cart.
* Practice HTML, CSS, and JavaScript.

## 3. Features

* **Product Display:** Shows products such as headphones, smart watches, shoes, and handbags.
* **Product Search:** Allows users to search for products by name.
* **Shopping Cart:** Users can add products to the cart and view the item count.
* **Category Section:** Displays categories such as Electronics, Fashion, Beauty, and Home & Living.
* **AI Shopping Assistant Demo:** Displays a welcome message when users try the assistant.
* **Responsive Design:** Adjusts the website layout for different screen sizes.
* **Navigation Bar:** Provides links to the Home, Categories, Products, and Cart sections.

## 4. Technologies Used

* **HTML5:** Structures the website content.
* **CSS3:** Styles the website and provides responsive layouts.
* **JavaScript:** Adds product search, cart counter, and assistant demo functionality.
* **Git & GitHub:** Used for version control and project hosting.

## 5. Project Structure

* **index.html** — Contains the structure and content of the website.
* **style.css** — Handles the website's design, colors, layout, and responsive styling.
* **script.js** — Manages product search, the cart counter, and the shopping assistant demo.
* **images/** — Contains product images and the website banner.
* **README.md** — Provides information about the project, its features, and how to run it.
* **E-Commerce Website UI.pdf** — Contains screenshots of the website.

## 6. How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.
5. Explore the products, test the search bar, and try the cart functionality.

## 8. Limitations

* The website does not use a real payment system.
* Product information is static.
* The shopping cart is a basic demonstration and does not process real orders.
* The AI Shopping Assistant is a demo and does not use an actual AI model.
* User accounts and database integration are not implemented.
